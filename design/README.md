# Mockups (histórico)

Estes arquivos (`web/` e `mobile/`, canvases `.dc.html`) foram os **primeiros mockups visuais** do ACUMULAAI, criados antes de existir qualquer código Flutter real — ver [SPEC.md](../docs/SPEC.md) seção 10 para a linha do tempo completa.

Desde 2026-09-15, o projeto passou a ter código Flutter real em [`web/`](../web) e [`mobile/`](../mobile), com um escopo que evoluiu bem além do que está desenhado aqui (mecânica de fidelidade configurável, campanhas, aprovação de compras, cores da marca, etc. — ver [docs/MECANICA_FIDELIDADE.md](../docs/MECANICA_FIDELIDADE.md)).

**Esta pasta não é mais atualizada.** Mantida só como referência histórica de como o produto começou a ser desenhado. Para o estado atual das telas, veja o código em `web/lib/screens/` e `mobile/lib/screens/`.
